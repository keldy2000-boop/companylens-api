How a lookup works

The x402 payment flow is handled by your agent's HTTP client. Nothing to configure on the buyer side — the protocol is self-describing.

01
Agent sends a plain GET request
No auth header, no API key. The endpoint is public.
GET https://api.companylens.xyz/company/09280351
02
Server returns HTTP 402 with payment terms
Response includes asset, amount, network, and recipient wallet. The x402 client reads this automatically.
HTTP 402 · X-Payment-Required: { asset: "USDC", amount: "0.50", network: "algorand:mainnet" }
03
Agent signs and submits payment to Algorand
The x402 client constructs an Algorand USDC transaction, submits it to the GoPlausible facilitator, and receives a signed payment proof.
USDC ASA 31566704 · GoPlausible facilitator · instant finality
04
Request retried with payment proof
Same request, same URL — this time with an X-Payment header containing the proof.
05
Server verifies, fetches data, returns profile
Middleware calls the facilitator to confirm on-chain settlement. Companies House data is fetched across five parallel endpoints. Claude synthesises the risk profile. JSON returned.
risk_score · risk_level · flags · ownership · recommendation

Integrate in minutes

Your x402 client handles the payment flow automatically. Three lines of setup, then call the endpoint like any other API.

// npm install x402-fetch algosdk import { wrapFetchWithPayment } from 'x402-fetch'; const fetch = wrapFetchWithPayment(globalThis.fetch, { wallet: process.env.ALGORAND_PRIVATE_KEY, network: 'ALGORAND_Mainnet_CAIP2', }); const profile = await fetch( 'https://api.companylens.xyz/company/00445790' ).then(r => r.json()); // profile.risk_score → 0–100 // profile.risk_level → 'low' | 'medium' | 'high' // profile.flags → [{type, icon, text}] // profile.recommendation → actionable string
# pip install "x402-avm[httpx]" algosdk from x402.client import x402Client from x402.avm import AlgorandSigner import os signer = AlgorandSigner(private_key=os.environ["ALGORAND_KEY"]) client = x402Client(signer=signer, network="ALGORAND_Mainnet_CAIP2") async with client as c: profile = (await c.get( "https://api.companylens.xyz/company/09280351" )).json() # profile["risk_score"], profile["flags"]
